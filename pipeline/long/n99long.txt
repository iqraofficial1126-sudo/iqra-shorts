True value എന്നത് ഒരു quantity-യുടെ exact value ആണ്, പക്ഷേ practically അത് ഒരിക്കലും അറിയാൻ കഴിയില്ല. True error equals measured value minus true value. True value അറിയാത്തതുകൊണ്ട്, നമ്മൾ most probable value ഉപയോഗിക്കുന്നു, അതായത് available observations-ൽ നിന്ന് true value-നോട് ഏറ്റവും അടുത്ത value.
